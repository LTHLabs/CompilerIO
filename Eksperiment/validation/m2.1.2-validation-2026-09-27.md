## 1. Objective

Make `platformio.ini` the single dependency manifest, install Registry libraries before compile with network on and the Base Environment read-only, then compile with network off. Enforce Registry-only, owner-qualified `lib_deps` at the agent boundary. Fix the Web App payload so the request body matches `BuildRequest.lib_deps: list[str]`. Prove the whole pipeline end-to-end through the real UI.

## 2. Final architecture / flow

Order in `run_build` (`local-agent/app/main.py`):

1. `validate_lib_deps` — Registry-only, owner-qualified.
2. `write_project` — write `platformio.ini` (with `lib_deps`) and `src/main.cpp`.
3. `prepare_dependencies` — dependency preparation phase.
4. `run_platformio` — compilation phase.
5. `merge_firmware` — `esptool.py merge_bin` into `wokwi-firmware.bin`.

Isolation and network:

| Phase | Wrapper | Base mounts | Network |
|---|---|---|---|
| Dependency preparation | `unshare --user --map-root-user --mount` (`environment.py:_run_dependency_preparation`) | read-only | **ON** |
| Compile + `merge_bin` | `unshare --user --map-root-user --mount --net` (`environment.py:_run_with_readonly_base`) | read-only | **OFF** |

Base Environment integrity: SHA-256 manifest (relative path, mode, size, mtime) taken at `prepare` and re-checked before and after every phase; mismatch drops the environment into ERROR.

Dependency contract: `python -m platformio pkg install --project-dir <dir> --environment esp32dev` reads `lib_deps` from `platformio.ini` and installs Registry libraries into `<project>/.pio/libdeps/esp32dev/` including transitive dependencies. Only owner-qualified specs (`owner/name@version`) are accepted.

Web App → Agent data flow:

```
Web App state:   selectedLibDeps = [{ header, platformioName }, ...]  (object[])
build.js:        selectedLibDeps.map(dep => dep.platformioName)
API payload:     lib_deps: ["owner/name@x.y.z", ...]                  (string[])
BuildRequest:    lib_deps: list[str]  → validator → platformio.ini
```

## 4. Files changed (M2.1.2)

Only Python and Web App files listed; no Base Environment change.

- `local-agent/app/dependency_validator.py` — require owner-qualified Registry specs (`owner/name...`); the URL/git/`file://`/absolute/relative rejections are unchanged. In-process unit checks: accepts `adafruit/DHT sensor library@1.4.4`; rejects `DHT sensor library@1.4.4`, `https://x/y.git`, `git+https://…`, `git@github.com:a/b`, `file:///x`, `/abs`, `./rel`, `../rel`, `~/h`, the empty spec, and `adafruit/DHT sensor library@^1.4.7`.
- `local-agent/app/environment.py` — `_run_dependency_preparation` now runs `python -m platformio pkg install --project-dir <dir> --environment esp32dev` (reads `platformio.ini`) instead of a per-library shell loop; the `--net` flag was removed from the dependency-preparation wrapper only. Compile wrapper still uses `--net`. Read-only Base mounts, `start_new_session=True`, manifest re-checks, and the `killpg(SIGKILL)` timeout path are preserved.
- `local-agent/app/main.py` — `run_build` no longer passes `lib_deps` to `prepare_dependencies`; call signature aligned. `BuildRequest.lib_deps` remains `list[str]`. No route or contract change.
- `web-app/library.js` — `EXTERNAL_LIBRARY_MAP['DHT.h'].platformioName` is `adafruit/DHT sensor library@1.4.4`. Other entries are unchanged; they remain ownerless and are out of scope for this milestone (see Section 6).
- `web-app/build.js` — payload conversion: `selectedLibDeps.map(dep => dep.platformioName)` before `api.build(...)`.
- `web-app/{editor,library,logger,pairing,prepare,build,wokwi}.js` — added the missing named `export { ... };` so `app.js` and `build.js` can import them as ES modules. No object-shape or behavior change.
- `web-app/state.js` — added `export { AppState };`. No behavior change.

Not touched: `local-agent/app/{config,security,lifecycle}.py`, `web-app/{api,app}.js`, `index.html`, `style.css`, Base Environment, PlatformIO config templates.
